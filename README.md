# OpenDepth

Repurposing Image Editing Priors for Robust Open-World Monocular Depth Estimation.

ACM Multimedia 2026. Mengke Zhang (Project Leader), Tianyi Yang, Xinzhuo Li, and Anlong Ming.

This repository hosts the academic project website, paper, and qualitative visualizations. Research implementation and arXiv links will be added when available.

The qualitative images use the epoch016 disparity checkpoint with 10 inference steps. Benchmark numbers are reported from the paper.
